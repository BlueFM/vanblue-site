# Moonlit Grimoire · 月下研究手札

> vanblue.online 全站 UI 设计规范 · 2026-11-28
> 定位：有巫师猫陪伴的个人研究藏书室，而不是游戏宣传页或占星商店。

## 1. 设计目标与边界

1. 第一眼看清真实姓名、硕士身份、学校与研究方向；一次点击到达 Publications、CV、Email。
2. 魔法来自装帧、配色、星图与页边细节，不靠遮挡内容的粒子、背景视频或开场动画。
3. 保留现有全部内容、URL、PDF、学术元数据、CCF 工具和优化器实验。论文状态不改写、不新增未公开指标。
4. 既有念咒猫是唯一可移动的巫师猫。点猫释放当前选择；月亮只打开设置；新彩蛋不改其选择和显隐，也不主动开关设置。普通点击外部关闭面板的原有规则照旧。
5. 本轮交付完整新模板、设计说明与真实浏览器预览；在独立分支审阅，不自动覆盖线上旧站。

## 3. 核心视觉系统

### 3.1 配色

| Token | 颜色 | 用途 |
|---|---|---|
| `--sky` | `#201828` | 夜空、导航、全站外框 |
| `--sky-deep` | `#17131F` | 深层背景、暗部 |
| `--sky-soft` | `#30233C` | 藏书票与深色装饰块 |
| `--paper` | `#F4ECDD` | 主要阅读纸面 |
| `--paper-light` | `#FFF9ED` | 小型阅读块与高亮纸面 |
| `--ink` | `#382C3F` | 主要文字 |
| `--muted` | `#71606F` | 日期、标签、次要说明 |
| `--link` | `#65417F` | 正文链接、主要交互 |
| `--link-hover` | `#492A62` | 链接悬停、按下 |
| `--amethyst` | `#B69ACB` | 深底上的紫水晶点缀 |
| `--gold` | `#B7955E` | 边框、星图和装帧；不用于纸面小号正文 |
| `--gold-ink` | `#7F612D` | 纸面上的金色标签文字 |
| `--rule` | `#DDCEB9` | 章节分隔与非交互边框 |
| `--control-line` | `#8B768C` | 输入框与交互边界 |
| `--mint` | `#58C69D` | 小鱼实体与少量生命感点缀 |
| `--mint-ink` | `#205C47` | 小鱼深色轮廓，纸面上也清晰 |

原则：浅金和浅紫用于装饰，不拿来承载长文；正文深墨色与暖纸保持高对比。表单、焦点和已选状态除了颜色，还通过边框、字重、下划线或 ARIA 状态表达。

### 3.2 字体与层级

- 展示标题：**Fraunces 600**，本地托管 Latin WOFF2，保留 SIL OFL。无外部字体请求；失败回退 Georgia。
- 导航、按钮、元信息、工具：系统无衬线字体，兼容中文系统字体。
- 长文：Georgia / 中文衬线回退，正文 17–18 px，行高约 1.8，阅读宽度约 65–72 字符。
- 首页姓名：桌面约 64–80 px，手机约 40–48 px；不用难读的哥特体。
- 页面标题：桌面 36–46 px，手机 30–36 px。
- 章节标题：28–34 px；条目标题 22–27 px。
- 元信息：11–13 px；辅助标签可用大写与轻微字距，不用于长句。

### 3.3 网格与留白

- 桌面内容最大宽约 1200 px，左右安全留白 24–40 px。
- 首页独立宽幅开场；下方主阅读栏与边注栏约 `2.2 : 1`，间距 24 px。
- 内页：约 232 px 的个人资料栏 + 弹性阅读纸页，间距 28 px。
- 840 px 以下：导航折叠；正文单栏优先，横向身份卡移到正文之后；DOM 与键盘阅读顺序一致。CCF / Lab 使用短说明与原生可展开帮助，不让长介绍把搜索和画布挤出首屏。
- 640 px 以下：阅读页内边距约 22 px，外边距 12–16 px；内容不依赖横向滚动。
- 交互目标优先不小于 44 × 44 px；长表、代码和公式允许在局部容器横向滚动，不撑开整页。
- 底部为猫与固定月亮保留空间，重要页脚链接不永久压在宠物下方。

### 3.4 形状与材质

- 主表面像装订书页：暖纸底、单层细边框、极轻的双线装帧与角部标记。
- 圆角有限使用：纸页约 4–10 px；按钮 6 px；星盘与藏书印保留圆形。
- 原创 SVG：月牙、四角星、轨道、线形星图、书籍与羽笔。静态、可缓存，不使用商业游戏资产。
- 页面背景只用稀疏星点与低对比的静态光晕；没有循环飘雪、鼠标拖尾或大面积闪烁。

### 4.2 手机首页

- 顶部一行：品牌 + 44 px 的 “Index” 导航开关；无 JavaScript 时直接显示全部导航。
- 首屏姓名、短简介与 CTA 在主阅读顺序中；头像/星图缩成右上方藏书印，不让大插画挤走身份信息。
- 两个 CTA 在窄屏可上下排列；宽度不固定，不裁切文字。
- 正文与边注自然单栏；论文不变成必须横滑的轮播。
- 猫保持原有小尺寸和不漫游规则；月亮仍在右下角。

## 5. 组件与交互状态

### 导航

- 当前页有明确的字色与下划线；不是只靠 hover 才能辨别。
- 手机 Index 开关维护 `aria-controls` / `aria-expanded`。
- Escape 关闭并返回开关；点击外部或选择链接关闭；切到桌面完整显示。
- Skip to content 链接在键盘焦点时可见。

### 链接、按钮、标签

- 正文链接带下划线；纸面主要按钮为深紫底浅字，次要按钮为描边或文字。
- hover 只做轻微颜色/边框变化，不放大整张论文卡、不倾斜正文。
- focus-visible 使用明确的外轮廓；不移除浏览器键盘可见性。
- 标签非交互时不伪装成按钮；论文状态明确区分发表与 under review。

### 念咒猫与鱼

- 现有耳朵修复、局部眨眼、7 个待机动作和更高触发频率不改。
- 鱼从半透明浅绿改为**实色翡翠绿 + 深色轮廓 + 轻量浅色边缘光**；白纸、暖纸、暮紫三种背景都要检查。
- 鱼轨迹与火花也提高饱和度；不靠把整屏染绿来改善可见性。
- 所选魔法、收起、漫游的本地偏好兼容现有存储结构。
- 不能通过点击品牌或彩蛋偷偷改成另一种法术，也不能自动打开设置。

## 6. 三个可访问的小彩蛋

| 触发 | 反馈 | 边界 |
|---|---|---|
| 点击首页藏书印 / 星座头像 | 星盘短暂点亮；播报 “Constellation found: curiosity.” | 原生 button，可键盘触发；不弹模态框 |
| 点击页脚的 margin note 按钮 | 在原位置切换一句轻松的研究边注 | 默认句无 JS 也能读；无占卜结果与伪科学陈述 |
| 页脚星星按钮，或非输入区键入 `lumos` | 至多 9 个有限星光，约 2.6 s；短状态提示 | 触屏有等效入口；不监听鼠标移动、不启动循环粒子 |

- 仅在用户主动触发后出现，不隐藏正式内容。
- `prefers-reduced-motion` 取消运动，保留静态或文本反馈。
- 切后台立即清理暂态与计时器；连续触发重启同一效果，不累计节点。
- 可在本地记住已发现彩蛋，不发送访问行为或新网络请求。
- 状态区域 `role=status / aria-live=polite`，不抢焦点、不遮住月亮。

## 7. 性能、回退与隐私

- 原生 HTML / CSS / JavaScript + Zola；不加 React、WebGL、远程字体服务、音频或新统计 SDK。
- 新字体本地托管、`font-display: swap`；头像给固定尺寸，减少布局跳动。
- 装饰 SVG 与少量 CSS 渐变静态绘制，无全屏 Canvas 背景循环。
- 无 JS 时：所有内容和桌面/手机导航可访问；猫和交互彩蛋不阻塞阅读；CCF 保留现有回退。
- blocked localStorage 时捕获异常，魔法与导航照常工作。
- 打印隐藏夜空、装饰、导航、彩蛋和猫；恢复白底黑字的正式阅读文档。
- 新设计不收集额外个人信息，不修改远端服务配置。

## 8. 实施与验收

### 文件组织

- `templates/base.html`：新的全站外框、导航、纸页、页脚与静态装饰。
- `templates/index.html`：新首页编排，继续读取原内容与数据。
- `templates/partials/`：身份卡、期限边注和原创星图组件。
- `static/css/moonlit.css`：设计 tokens、全站版式与主题组件；旧 `style.css` 保留成熟的内容/工具基础样式。
- `static/js/grimoire.js`：独立导航与有限彩蛋；不侵入 Guardian。
- `static/css/guardian.css`：仅必要的鱼可见性调整。
- `static/fonts/`：自托管字体、来源与 OFL。
- `design/`：设计板和实际页面预览；与完整模板一并交付。

### 必须通过

1. Zola 构建与 JS 语法检查；检查所有页面内部链接和静态资源。
2. 桌面、390 px 手机、320 px 窄屏的布局；各页面无整页横向溢出。
3. 首页、论文、长文、CCF 与 Lab 的代表性真实浏览器视觉检查。
4. 全部导航与按钮键盘可用；手机菜单 ARIA、Escape 和焦点返回正确。
5. 猫点击保持当前魔法，月亮仍只开设置，旧偏好不丢失；鱼在三种底色上清楚。
6. 三个彩蛋有限、可重复触发、可清理，触屏等效、reduced-motion 与 hidden 状态正确。
7. CCF 搜索/等级/历史/深链仍工作；Lab 播放/暂停/重置与拖动仍工作。
8. 无 JS、存储禁用、打印回退；无浏览器未捕获异常。
9. 真实资料不变；不改服务器，不把审阅分支误部署到线上。

发布方式：确认预览后，将本分支合入 main，沿用原有 GitHub Actions 原子部署流程。构建产物与预览不代替源码。
