# vanblue.online 魔法主题设计参考调研

- 调研日期：2026-11-28
- 目标：为与紫帽巫师猫匹配的学术个人站确定整体设计方向，而非仅给现有模板换紫色。
- 方法：先用 `web_search` 寻找真实网站或明确客户案例，再用 `web_fetch` 核实关键页面；排除 AI 生成模板营销页、纯图片 Pin 和仅名称含有 Magic 的无关公司。
- 证据边界：第一阶段以正文与设计方说明为依据；第二阶段补充了四个参考的真实 Chrome 首屏截图及计算样式，见文末。下文保留初次抓取时的证据边界，区分“正文结构”“设计方描述”与“实际看到的首屏”。HTTP 状态及可访问性仅代表本次抓取结果。

## 三、设计结论：知识组织＋编辑式书页＋紫色天体

**建议主题：紫帽巫师猫的私人研究藏书室。**

它不是“学术模板换紫色”，也不是“必须探索才能使用的游戏站”。完整性来自贯穿首页、列表、详情、导航与交互状态的同一设计系统。

### 1. 知识组织作为骨架

- 用 BnF 的分层资料组织与 Myles 的手札互链作为信息架构参考。
- 一级导航保留 About、Research、Publications、Projects、Notes、Contact 等明确语义；魔法名称只作为副标题或装饰层，不替代可理解的功能名称。
- 论文继续呈现作者、年份、期刊／会议、DOI、PDF、Code 等真实元数据；研究札记明确标记日期和成熟度。
- 首页即可识别姓名、学校／身份、研究方向，并直接进入论文、CV 和联系方式。

### 2. 编辑式书页作为内容容器

- 把网站当成一本可检索、持续增补的研究手册，而不是若干互不相关的营销卡片。
- 全站统一章节编号、页边索引、题签、细线边框、插图位置与书目条目格式；让首页、项目页和论文页拥有共同的出版物感。
- 正文采用干净的阅读表面与明确层级；避免以脏旧纸纹、华丽字体和过密装饰模拟“古老”，损害长文与公式阅读。
- 紫帽猫可出现在封面式首屏、章节扉页或空状态；不应在每张论文卡上重复抢占注意力。

### 3. 紫色天体作为视觉语言

以下是拟议设计方向，不是对参考站视觉的实测：

- 深梅紫／午夜紫用于外层空间，紫水晶色用于交互强调，暖纸白用于主要阅读面，少量暗金用于细线与题签。
- 通过星图细线、轨道圆弧、月相式标记与留白建立天体感，不使用大面积高亮霓虹和随机粒子代替设计。
- 优先使用统一、原创或合法授权的插图体系；紫帽猫、书籍、研究工具和星图应属于同一个画风。
- 动效只承担反馈和轻微氛围：可关闭、尊重减少动态效果设置，不影响滚动、键盘操作与正文读取。

## 四、不可越过的边界

1. **没有截图证据，就不声称看过截图、视觉构图、真实动画或交互效果。** 设计方文字描述必须与独立视觉验证区分。
2. **游戏美术、商业插画、书籍装帧图、字体和装饰资源不是免费素材。** 参考其组织原则与设计方法，不直接下载复用；落地时另行确认授权，或采用原创／明确许可资源。
3. 不让“魔法感”削弱学术可信度：论文状态、学校身份、研究内容和外链应准确，装饰性世界观不应造成现实资历误解。
4. 本文是调研与设计方向，不等同于网站实现、素材授权审查或新模板的浏览器验收。
