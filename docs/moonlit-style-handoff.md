# Moonlit Grimoire · 月下研究手札｜风格交接与复用指南

> 日期：2026-11-28。用户已确认喜欢此版本，后续设计可以延续这一方向。
> 用法：将本文件单独上传到新对话，再说明要改的页面或项目。核心规则已写全，不要求新对话拥有之前的聊天记录。

## 1. 一句话定义

**暮紫夜空包围暖纸书页，以暗金星图、紫晶交互和巫师猫营造魔法藏书室，同时保持学术网站的清晰、可信与可读。**

关键词：`Moonlit Grimoire`、`academic editorial`、`fantasy bookbinding`、`celestial marginalia`、`warm parchment`、`restrained magic`。

风格不是简单的“紫色网站”：辨识度来自 **深色外框 / 浅色阅读区的层次、书籍装帧、衬线标题、章节式信息结构、克制的小彩蛋**。

## 2. 这次具体更新了什么

- 将原本偏白底的学术站统一为魔法研究手札：导航、首页、论文、研究、项目、博客、CV、CCF 日历、Lab 与 404 都属于同一视觉体系。
- 首页采用“研究者介绍 + 星图藏书票”的开场；下方是编号书目、研究故事、项目、经历和边注。
- 新增原创 SVG 星图、月牙、书与羽笔；更新同风格 favicon 与社交分享封面。
- 新增三个主动发现的小彩蛋：藏书印、页脚边注、有限星光。
- 小鱼从浅色半透明改为不透明翡翠绿、深轮廓与浅色光晕，在白底和深底都可见。
- 手机内页正文优先，身份卡在后；工具页用短介绍与可展开帮助，优先展示搜索和画布；窄屏 Lab 统计表只在自身区域滚动。
- 保留原有学术内容、URL、论文元数据、科学图形及猫咪设置逻辑，不因换皮改写事实。

## 3. 可直接迁移的视觉规则

### 配色 Tokens

以下为实际实现中的核心值。迁移到其他技术栈时可映射为 theme tokens 或 CSS variables。

```css
:root {
  --sky: #201828;          /* 全站外框、导航：暮紫夜空 */
  --sky-deep: #17131F;     /* 夜空暗部 */
  --sky-soft: #30233C;     /* 深色藏书票与装饰块 */
  --paper: #F4ECDD;        /* 主阅读纸面 */
  --paper-light: #FFF9ED;  /* 高亮纸面与按钮文字 */
  --ink: #382C3F;          /* 主文字 */
  --muted: #71606F;        /* 日期与次要文字 */
  --link: #65417F;         /* 紫晶链接、主按钮 */
  --link-hover: #492A62;
  --amethyst: #B69ACB;     /* 深色背景上的淡紫点缀 */
  --gold: #B7955E;         /* 装饰金：星图、细边框 */
  --gold-ink: #7F612D;     /* 文字金：纸面标签 */
  --rule: #DDCEB9;         /* 非交互分隔线 */
  --control-line: #8B768C; /* 输入框与交互边界 */
  --mint: #58C69D;         /* 翡翠绿小鱼 */
  --mint-ink: #205C47;     /* 小鱼深轮廓 */
}
```

**使用原则：** 大面积暖纸承载信息，暮紫负责包围和建立氛围，金色只点缀。装饰金与文字金不能混用；浅金、浅紫不承担纸面小号正文。不能用低透明度把关键信息“融进背景”。

### 字体与排版

- 展示标题：**Fraunces 600**；当前实现为本地 Latin WOFF2，约 35 KB，附 SIL OFL。回退 Georgia；中文使用系统衬线字体。
- 长文：Georgia / 中文衬线回退，约 17–18 px，行高约 1.8，阅读宽度约 65–72 字符。
- 导航、按钮、工具与元信息：系统无衬线；代码使用系统等宽。
- 首页姓名在桌面约 64–80 px，手机约 40–48 px；内页标题桌面约 36–46 px、手机约 30–36 px。窄屏以不挤压、不溢出为先。
- 题名、作者、日期与状态分层；装饰性小写标签可用大写和字距，但重要信息不能靠极小文字承载。
- 不使用大段哥特字体、花体正文，也不把整站变成发光的游戏 HUD。

### 布局、材质与组件

- 桌面最大内容宽约 1200 px；内页约 232 px 侧栏 + 弹性阅读区；主要间距 24–28 px。
- 首页宽幅纸页：左侧姓名 / 简介 / 论文与 CV 入口，右侧拱形星图藏书票。下方主内容与边注约 2.2:1。
- 论文和项目使用“书目行 + 编号 + 细分隔线”，不要把每一小段都拆成大圆角卡片。
- 纸页使用细边框、轻双线、角部记号、很淡的阴影；圆角约 4–10 px。星盘和藏书印可用圆形。
- 背景星图稀疏、低对比、静态。装饰集中在边缘，阅读中心保持安静。
- 840 px 以下折叠导航、单栏排版；640 px 以下收紧留白。正文和工具优先于个人资料卡，DOM / 焦点顺序与视觉顺序一致。
- 手机交互目标优先不小于 44×44 px。长表、代码和公式可以局部横向滚动，但不能撑开整页。
- 科学图表保留原有数据、语义颜色和图例，不为统一紫色而破坏信息表达。

## 4. 魔法与交互：轻量、可选、可退出

### 三个已实现的彩蛋

1. **首页藏书印**：点击头像印章，短暂点亮星座并显示文字反馈；不是打开新的个人资料弹窗。
2. **页脚边注**：点击可循环五句短札记，轻微增加“翻阅手札”的感觉。
3. **星光**：点击页脚星星，或在非输入区域键入小写 `lumos`，出现最多九颗星，约 2.6 秒清理；重复触发不累积节点。

输入框、文本域、可编辑区域不触发键入彩蛋；减少动态效果时只保留静态反馈；标签页隐藏时清理临时效果。发现记录只用本地存储，禁用存储时照常可用。不要新增追踪、音频、开场动画、持续粒子循环或鼠标拖尾。

### 原有念咒猫的约束

- **点猫 = 释放当前选中的法术**；不能改成轮换法术或打开设置。
- **月亮 = 打开 / 关闭设置**；猫隐藏后月亮仍可用，设置面板锚定月亮而非猫的位置。
- 选择法术会保存并关闭面板，**不会立刻施法**；“预览”才施法。
- 保留键盘、隐藏 / 恢复、拖动、减少动态效果与原有偏好，不因新增彩蛋改变这些状态。
- 新彩蛋不调用猫 API 去改选择或显隐；既有“点击外部关闭设置”规则仍有效。
- 没有明确需求时，不重画猫、不换素材、不重写原业务脚本。

### 鱼特效的对比度要求

实体填色 `#58C69D`，填充不透明；轮廓 `#205C47`，配浅色光晕。当前主体路径的 stroke-width 为 SVG 坐标中的 4，**不是要求缩放后仍为 4 个 CSS 像素**。必须分别检查纯白、暖纸、暮紫三种背景，不能只在深色背景上看着漂亮。

## 5. 内容与实现边界

- 导航继续用清楚的 Publications / Research / Projects / Blog 等语义，不让访客先学会游戏术语才能找到论文。
- 不编造作者、学历、学校、年份、论文状态、实验结果、PDF 或外部链接。未定稿仍为 Under review，装饰页眉也不附加似是而非的发表年份。
- 新项目可以复用视觉语言，但不能顺带复制本站姓名、论文、备案等身份内容。
- 适配目标项目现有技术栈，不要求所有项目迁移到 Zola，也不为换皮引入新框架。
- 本站现有样式加载顺序为 **基础样式 → 猫样式 → Moonlit 主题覆盖**；基础样式还承担论文、长文和工具功能，不能当作废代码整份删掉。
- 图像与字体尽量本地托管；保留字体和第三方数据许可。装饰使用原创 SVG，不提取商业游戏角色、视频或素材。
- 保留可见焦点、语义标题、Skip link、ARIA 状态、打印与无 JS 阅读退化能力。文字对比度以正常文本至少 4.5:1 为目标，不能只检查色板而不检查实际页面。

## 6. 后续协作方式：少重复、少无效消耗

1. 已确认此风格，无需每次重做全网调研；先检查目标项目与少量关键入口。
2. 沿用上述语言，说明新需求如何映射到现有组件，再实现必要差异；不为展示过程重写整站。
3. 视觉修改用有代表性的桌面 / 手机实页验证；纯文档或非视觉逻辑改动不额外截图。
4. 对实际改动做对应构建、功能或结构检查；历史验证不等于新修改自动通过。
5. 未明确要求时只做本地修改 / 预览，**不推送 main、不部署、不覆盖线上站点**。
